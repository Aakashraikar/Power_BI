# Power_BI

This project is an interactive Power BI dashboard built to analyze and visualize ecommerce sales data. It provides actionable insights into sales performance, profitability, customer behavior, and product trends using dynamic visuals and data modeling.

⚡ Key Features
📌 KPI Cards
Total Sales Amount: 438K
Total Quantity Sold: 6K
Total Profit: 37K
Average Order Value (AOV): 121K
📈 Visual Insights
Profit/Loss by Month – Column chart highlighting monthly trends and seasonality
Top States – Bar chart showing highest revenue-generating regions
Top Customers – Identifies key contributors to sales
Quantity by Category – Donut chart (Clothing, Electronics, Furniture)
Profit by Sub-Category – Highlights most profitable product segments
Quantity by Payment Mode – Distribution across COD, UPI, Cards, EMI
🎛️ Interactivity
Quarter slicer (Q1–Q4)
State filter dropdown
Cross-filtering across visuals for drill-down analysis
🧠 Data Modeling
Star schema approach with:
Fact Table: Orders/Sales data
Dimension Tables: Customers, Products, Geography, Date
Relationships created to enable efficient filtering and aggregation
